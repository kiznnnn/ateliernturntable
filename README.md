# atelier⁰¹ — PC-4 Direct-Drive Phonograph System

Interactive Web Audio vinyl turntable and crate browser with 3D Record Sleeve Carousel:

- **`index.html`**: Main application entry point (`styles.css`, `catalog.js`, `audio-engine.js`, `app.js`).
- **`atelier-pc4-standalone.html`**: Single-file self-contained edition.
- **Features**:
  - 33⅓ & 45 RPM direct-drive platter physics, pitch slider (±8%), needle drop cueing, and real-time FFT spectrum analyzer.
  - 3D Interactive Record Sleeve Carousel (`#sleeveCarouselStage`) with drag, wheel, keyboard, and 1-click *Spin on Platter*.
  - Curated vinyl catalog including *Views* by Drake and *The Miseducation of Lauryn Hill* by Lauryn Hill with automatic Apple Music stream hydration.
